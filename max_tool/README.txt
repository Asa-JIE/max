MaxTool Framework
==============================

回归测试步骤：

1.
解压：

E:\max_tool

2.
双击：

install.bat

3.
重启 3ds Max 2020

4.
检查顶部菜单：

max-tool

5.
检查子菜单：

rig
mesh
help

6.
点击：

help
    Help

弹出：

max_tool 加载成功
